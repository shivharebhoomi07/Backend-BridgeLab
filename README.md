# File System Operations - Node.js Assignment

This module demonstrates Node.js fs operations including:

- Reading Files
- Writing Files
- Copying Files
- Deleting Files
- Directory Handling
- Streams
- Error Handling

Branch Name: fs-assignment

## How To Run

node src/readFiles.js  
node src/writeFiles.js  
node src/copyFiles.js  
node src/deleteFiles.js  
node src/directoryOps.js  
node src/streams.js  
node src/errorHandling.js
